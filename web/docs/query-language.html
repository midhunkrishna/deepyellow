Query language

One small language, used everywhere. Press / to type a query. It filters every view live, and brushing in Spectrum or Field writes into it, so the filter is always visible and editable.

size>100mb age>1y kind:video -path:Photos ext:mov,mp4 is:clone mark:remove safe:safe

A query is a list of terms separated by spaces. A file must match all of them. Put a - in front of a term to negate it. Wrap text that contains spaces in double quotes: path:"Application Support". At most 24 terms are used.

Query or SQL #

The query is the quick filter that works in every view as you type. For joins, grouping, sums and calculations, use SQL: a SQL result with an id column becomes the set every view shows. They combine, and a node must match both.

Terms #

TermMatches
size>100mb, size<1gbSize greater or less than a value
age>1y, age<2wTime since last modified
opened>6m, opened<3dTime since last opened (accessed)
kind:videoA kind. See below. Commas combine: kind:video,audio
ext:mov,mp4File extension, with or without the dot
name:backupThe name contains the text
path:PhotosThe name or any parent folder's name contains the text
path:Library/CachesWith a /, the full path contains the text
is:dirIs a folder: matches every file inside a matching folder
is:cloneShares its data with an APFS clone
is:hardlinkIs a hard link
is:packageIs a package such as an app or a library bundle
is:datalessIs an iCloud placeholder that is not stored here
mark:keep, mark:remove, mark:later, mark:noneYour decision on it
safe:safe, safe:rebuild, safe:review, safe:neverIts safety tier
anythingA bare word matches a name or a path

Matching is case-insensitive.

Units #

SizesDurations
b, kb, mb, gb, tb (decimal, 1 kb = 1,000 bytes)s seconds, h hours, d days, w weeks, m months (30 days), y years (365 days)

A bare number for a size is bytes. A bare number for an age is days. Decimals work: size>1.5gb.

Kinds come from the file extension, from macOS type information, and, for files that would otherwise be other, from a look at the first bytes of the file. See Architecture.

Mistakes #

A term that cannot be understood is ignored and listed under the query bar, for example "unknown kind" or "bad size unit". The rest of the query still applies.
